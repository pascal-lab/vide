Vide 1.3.0 是 1.3 系列的首个稳定版本。相比 1.2.x，本次更新将底层 SystemVerilog 前端升级至 Slang v11，为 `vide.toml` 带来完整的编辑器支持，并大幅扩展了工程级代码导航、语言特性覆盖与大型项目响应速度。

## 重点更新

### 升级至 Slang v11 前端

- 语法解析、语义诊断与宏源码定位全面迁移至 Slang v11，编辑器内的报错和警告更贴近真实编译器行为。
- 宏展开代码中的诊断范围更精确，减少整行错位或误报；语义诊断支持后台异步运行，编辑大型文件时不会阻塞输入。

### 工程级代码导航与大纲

- **转到类型定义**：支持从信号、变量或端口直接跳转到对应的 `typedef`、`struct`、`enum` 或 `interface` 声明。
- **双向调用层级（Call Hierarchy）**：可在函数或任务上查看“谁调用了它”以及“它调用了哪些子程序”。
- **模块与层级路径导航**：支持工程级模块实例化层级解析，以及跨层级的点号路径跳转（如 `dut.u_core.sig`）和 `interface modport` 成员跳转。
- **作用域与聚合类型成员跳转**：枚举字面量和 `struct` / `union` 成员现可作为独立符号解析，`STOP`、`pkg::STOP`、`cnt.ovf` 等写法均可直接跳转到声明；同时支持写在 `module` 头部端口列表之前的 `import pkg::*;`。
- **工作区符号搜索增强**：支持结果相关性排序与请求取消，并显示完整的所属模块或作用域路径，在大型工程中查找符号更加顺手。

### `vide.toml` 编辑器支持

- 打开 `vide.toml` 时，可直接获得配置项的悬停文档、自动补全、TOML 语法与字段诊断、文档大纲及代码折叠。
- 补全支持工程感知：输入配置键时列出可用选项，填写 `top_modules` 时自动补全当前工程中的模块名。
- 在 RTL 代码或 `vide.toml` 中重命名顶层模块时，会自动同步更新配置文件与对应的 RTL 引用。

### 签名提示、悬停与宏编辑

- **函数与系统任务签名提示**：调用自定义函数、任务以及 `$display`、`$clog2` 等系统任务时提供参数签名提示；系统调用支持实参名称提示（Inlay Hints）。
- **更清晰的悬停信息**：查看系统任务时显示参数与用途说明，查看断言和宏调用时可直观预览展开结果。
- **宏重命名与安全回退**：重命名操作已覆盖预处理宏与宏形参；当宏或 `include` 上下文不完整时，编辑器会保守跳过不确定的推断，避免给出误导性的补全或错误的批量修改。

### 更广泛的 SystemVerilog 支持

- 扩展了对常见设计与验证语法的识别与符号索引，包括 `class`、`constraint`、SVA 断言（`property` / `sequence`）、`clocking` 块、`checker`、`covergroup`、DPI 声明、`bind` 指令、自定义 `nettype`、`tagged union`、`program`、`let` 声明，以及 `randcase`、`disable fork` 等语句。
- 为 `checker`、`covergroup` 以及代码区域（region）新增代码折叠支持，文档大纲信息更完整。

## 性能与稳定性

- **按文件增量索引**：修改单个文件时仅重建该文件的语义索引，不再触发整个工程的全量重建；配合多级缓存，显著减少大型工程中的重复计算。
- **修复复杂宏导致的崩溃**：修复了嵌套宏展开以及宏参数使用默认值（如 `prim_assert` 断言宏常见写法）时语言服务器崩溃的问题。
- **其他稳定性修复**：
  - 修复 non-ANSI 端口列表中存在空拼接时触发崩溃的问题。
  - 修复工作区冷启动或初始化未完成期间请求阻塞、报错的问题。
  - 修复 macOS 下文件监听阻塞服务就绪的问题，以及 Windows 下的绝对路径处理问题。
