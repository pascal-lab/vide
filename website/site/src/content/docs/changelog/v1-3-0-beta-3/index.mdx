Vide 1.3.0-beta.3 是一个以真实工程稳定性为主的预发布版本：修复了常见宏写法
导致语言服务器崩溃的问题，并补全了 package 作用域下的名字解析。

## 重点变化

- 修复了宏参数取默认值时语言服务器崩溃的问题，例如 ibex 与 OpenTitan 中广泛
  使用的 `prim_assert` 断言宏。
- 支持 module 头部声明中的 import（`module m import pkg::*; (...)`），因此
  通配导入的类型、函数和枚举字面量都能解析。
- 枚举字面量与结构体成员现在是正式的定义：`STOP`、`pkg::STOP`、`value`、
  `cnt.ovf` 都能跳转到声明处。

## 修复

- 宏展开追踪改为按每次展开分配的宏缓冲区识别实例，嵌套宏与默认参数不再触发
  追踪不变量。
- 来自形参默认值的 token 按宏体 token 处理，不再被当成调用点并不存在的实参。
- module、interface、program 头部声明的 import 会 lowered 到对应作用域。
- 枚举字面量进入声明所在作用域的 value 命名空间与 package exports，通配导入
  因此也能看到它们。
- 聚合成员名字解析会跟随 typedef，同名端口不再遮蔽结构体字段。

## 已知限制

- 成员导航目前覆盖一层聚合嵌套，跨层级实例的链式访问仍有限制。
- 重命名等重构尚未把枚举字面量当作独立类别处理。
- 部分 SystemVerilog 语法已 lowering 但尚未完成完整语义分析，个别悬停和补全
  结果仍不完整。
- 该预发布版本仅通过 GitHub 分发；Marketplace 和生产文档站点跟随稳定版发布线。
